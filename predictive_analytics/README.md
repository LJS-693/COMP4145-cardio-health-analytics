# Predictive analytics

Use Python 3.12 and install `requirements-notebooks.txt` into the selected Jupyter kernel.
Run the four notebooks in order. Saved cell outputs include model comparisons, metrics and figures.

| Notebook | Task |
| --- | --- |
| `01_baseline.ipynb` | LR, RF and XGBoost baselines; fold metrics, comparisons and plots |
| `02_optimization_round1.ipynb` | LR C; RF depth/leaf size; XGBoost depth/child weight |
| `03_optimization_round2.ipynb` | Retain LR; tune RF and XGBoost sampling using round1 settings |
| `04_test_and_ranking.ipynb` | Fixed XGBoost round2 test metrics, scores, ranking and @10%–@100% capacity evaluation |

`training_utils.py` contains shared loading, pipelines, grouped CV, scoring and exports.
All four notebooks import this helper.

For a fresh run, choose a new `RUN_NAME` in all four notebooks. Training refuses to
overwrite an existing stage; notebook04 also uses a new `EVALUATION_NAME` when
repeating evaluation exports. It must load a model generated by notebook03.

Generated models, parameter metadata, candidate/fold results, figures and row-level
exports go under `runs/<RUN_NAME>/`. This directory is local and ignored by Git.
Notebook03 saves the model loaded by notebook04. Run notebooks01–03 before04
when starting from a fresh checkout.

Seven source inputs yield nine encoded columns. All models use the same grouped
five-fold development CV and mean validation ROC-AUC selection. Classification
metrics use 0.5; scores and ranking use continuous positive-class probabilities.
Test labels are excluded from input features and label-independent tie-breaking.
Notebook04 reports the full-test evaluation and a profile-overlap sensitivity check.
